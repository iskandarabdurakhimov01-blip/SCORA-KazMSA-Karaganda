# SCORA KazMSA Karaganda

Готовый адаптивный статический сайт на HTML, CSS и JavaScript.

## Как открыть

Распакуйте архив и откройте `index.html` в браузере. Для работы основных разделов сервер не нужен. Шрифт Manrope загружается из Google Fonts; без интернета используется системный шрифт.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите **содержимое** папки проекта в корень репозитория (файл `index.html` должен лежать в корне).
3. Откройте Settings → Pages → Build and deployment.
4. Выберите Deploy from a branch, ветку `main` и папку `/(root)`, затем Save.
5. Дождитесь публикации — адрес появится в разделе Pages.

## Что редактировать

- `index.html` — тексты, ссылки, разделы и контакты.
- `style.css` — цвета, шрифты, анимации и адаптивная верстка.
- `script.js` — мобильное меню, подсветка разделов и индикатор прокрутки.
- `assets/` — изображения и иконка сайта.
